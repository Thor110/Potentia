A small site for the Sieve extension. The pages linked below are .sieve files: the extension fetches each, checks it against the SHA-256 its link states (an integrity="sha256-..." attribute), has Sieve on this computer decode it, and shows the page it holds. Anything that does not match is refused.

Pages That Should Open

  • The gallery: a slideshow of .sieve pictures, one of them tampered with.
  • About: a page held in a .sieve, with a .sieve picture of its own.
  • Notes: another, which links back here.
  • Directory Listing Testing: four pictures in folders within folders, and a page among them, all in one .sieve. It opens as a listing of its folders and files, each with its size and SHA-256; open any file from it, and the page shows the pictures beside it by their paths in the same .sieve.
  • Every page in one .sieve: the site's own pages and stylesheet, opened as their listing.

Links That Should Be Refused

  • Notes, with the wrong hash: the link states the hash of an empty file.
  • Notes, with no hash: the link states none, so nothing vouches for the file.

Each link names a file below it by its hash, and the pages it opens link back here by name only. Two pages cannot each hold the other's hash: changing either would change both, without end. Instead the site has one table of every file's hash, index.sieve, whose own hash is the one to trust for all of it: the extension remembers it on your first visit, and shows this page and the gallery only once they are the ones it names.
