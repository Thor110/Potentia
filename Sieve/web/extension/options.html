Sieve: sites checked against their tables

A site built by sieve site build has a table, index.sieve: every file of the site by its SHA-256. The extension remembers each site's table the first time one of its pages leads to it, and from then on shows a page of that site only once it is the one the table names. If the table ever changes, it asks you first. sieve site build prints the table's SHA-256: save it here before you first visit, and not even the first visit is taken on trust.
