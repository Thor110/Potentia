Title : The Sieve of Potentia - Dynamic Modular State Space Compression Engine

Body :
For a number of years now I have been conceptualising a compression engine which I have named 'The Sieve of Potentia' and have finally been building it out over the past few months.

	Compression

The system utilises various compression methods for comparitive analysis throughout the encoding process.

Coupled with a final pass of custom search methods that improve the results, as well as breaking data down into chunks to test against various methods.

It includes a file delta scanner which optimises files when they contain much of the same data.

Example : WoWRevived which is a restoration project of mine for an old video game (Jeff Wayne's 'The War of the Worlds' the 1998 RTS PC game) contains two nearly identical files that it swaps between, one containing the regular minimaps and the other containing higher resolution minimaps.

The two files are scanned, the ~96% similarity is noted and the ~160mb file which is reduced to ~52mbs, becomes a ~2mb script that lifts the data from the other file as it is unpacked.

Alongside that it checks file hashes and trims exact duplicates to be a single file that gets unpacked accordingly.

As well as pattern matching that turns repeating byte patterns into instruction sets for procedurally regenerating those blocks of the data.

It also checks file contents for base64 representations of files to ensure they get compressed properly. ( ie : base64 jpeg embedded in html )

Then there is an auditable logger that details the exact formulae or recipe used for the files it compresses.

	Statistics

So far, most tests are outperforming 7zip, jpeg, png and in a number of instances brotli - update with other formats when ready to post NOTE

The written proof describes the basic functionality of the state space which theoretically allows for maximum compression under perfect circumstances.

Those circumstances would be finding the perfect balance through a filter applied to the state space which would shift the file you are searching for to an exact integer interval rotation in the state space.

Finding such a filter is the intractable part of the search, though I hold out hope to find a real file this way one day...

	AI Training Harness

The application also includes an AI training harness for training AI models locally.

My reasoning for this is that Potentia was the title for my thesis on AI alignment which can be found on the github pages and in the main readme.

You can read part of the thesis here : https://github.com/Thor110/Potentia/tree/main#why-it-exists

In short, just as with human beings we can not guarantee alignment, neither can we with AI systems, that is to say it is intractable but trackable with recorded ordering of training data.

Comparable to allowing an AI model to walk the Library of Babel to train on the data as it goes, inevitably, probability distribution becomes chaotic, messy and requires constant upkeep while making it impossible for models alone to overcome token weight conflicts.

Traditional AI training records model weights and checkpoints, but subtle hardware-level variations, thread scheduling differences, and floating-point round-off drift mean that reproducing a model bit-for-bit from scratch is notoriously difficult.

By enforcing strict integer-only arithmetic throughout the training loop—where every activation, gradient, and weight update is explicitly bounded, shifted, and quantized, Sieve ensures absolute, deterministic bit-reproducibility across any machine architecture.
