Title : The Sieve of Potentia - Dynamic Modular State Space Compression Engine

Body :
For a number of years now I have been conceptualising a compression engine which I have titled 'The Sieve of Potentia' and have finally been building it out over the past few months.

	Compression

The system utilises various compression methods for comparitive analysis throughout the encoding process.

Coupled with a final pass of custom search methods that improve the results, as well as breaking data down into chunks to test against various methods.

It also includes a file delta scanner which optimises files when they contain much of the same data.

Example : WoWRevived which is a restoration project of mine for an old video game (Jeff Wayne's 'The War of the Worlds' the 1998 RTS PC game) contains two nearly identical files that it swaps between, one containing the regular minimaps and the other containing higher resolution minimaps.

The two files are scanned, the ~96% similarity is noted and the ~160mb file which is reduced to ~52mbs, becomes a ~2mb script that lifts the data from the other file as it is unpacked.

Alongside that it checks file hashes and trims exact duplicates to be a single file that gets unpacked accordingly.

As well as pattern matching that turns repeating byte patterns into instruction sets for procedurally regenerating those blocks of the data.

It also checks file contents for base64 representations of files to ensure they get compressed properly. ( ie : base64 jpeg embedded in html )

	Statistics

So far, most tests are outperforming 7zip, jpeg, png and in a number of instances brotli - update with other formats when ready to post NOTE

	Security

All sieve files contain SHA-256 hashes of the files they contain and are checked when decoding and not written if the hashes don't match.

	Applications

The program is 'sieve.exe' which is a command line application, I also include a fun 'front-end' 3D n-dimensional state space explorer called 'hallway.exe' that comes packed with a number of tools and utilities.
