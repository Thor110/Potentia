# engine: towards a Sieve game engine (far future)

This folder points at the far aim in IDEAS ("Entering a world, and a games dimension"): every
game reduced to its smallest footprint and carried in `.sieve`, its worlds, models, sounds and code
pulled from the library's lines.

Nothing here is built into Sieve. Game formats have little use outside their games, so they stay
out of the main architecture (Edward, 25 October 2026); what is learned about them is kept here,
for the day an engine needs it.

| Notes | Game | What |
| :--- | :--- | :--- |
| [`wow.md`](wow.md) | Jeff Wayne's *The War of the Worlds* (1998) | its `.WoW` archives, `KAT!` and `SfxL`, measured |

**No game data is kept in the repository**, not even a small archive: tests, when there are any,
make their own archives from the repository's own files.
