# tone.mp3

A test file for Sieve's MP3 way (`pmp`, CI step 11): three seconds of two sine tones (330 Hz left,
550 Hz right), made here on 8 November 2026 by ffmpeg's lavfi sine source and coded by LAME (through
ffmpeg, `-q:a 4`, bit-exact flags), with an ID3 tag naming it. Made for Sieve; no recording in it.
