## zlib streams inside any file: built

**Measured first** (a prototype in Python: the streams found and inflated, LZMA2 at preset 6 of the
file as it is against the file with its streams opened, before preflate's differences): a git pack
of this repository (7,911,477 bytes, 2,737 streams) −28.3%; two WOFF fonts (Carlito and Caladea,
written by fontTools 4.55) −22.1% and −13.5%.

**Built.** `zlib_streams` (tools/cli/pack.cpp): in a file no other way has opened, every zlib stream
(a valid header, read by zlib to its end with its Adler-32 right, holding 64 bytes or more) carried as
what it holds, its deflate made again by preflate, the file made again by `sk` (v21, which every
reader since reads: no new recipe). Kept where `worth` finds it clearly smaller, after it gives the
file back. `--priority balanced --optimise-search`, each alone:

## PCX: built

**Measured first.** Six pictures written by ImageMagick 6.9.12 as PCX: Sieve carried them 42% (a
screenshot) to 66% larger than the same pixels as uncompressed TGA. Every plane line of all six, and
of Pillow 12's PCXs, is coded by the PCX specification's own coder (runs of up to 63, a byte of 0xC0
or more as a run of one), so nothing about the coding need be kept.

**Built.** `pcx_rle` (tools/cli/pcx_rle.cpp), a new recipe `pcx <skeleton size> <inner size>`
(format 28): the pixels, planes interleaved (so RGB is a picture three bytes a pixel, for mixing),
then a byte naming the coder (Pillow codes a line's padding byte alone), the header and the palette.
`--priority size --optimise-search`, each alone:

## Measured, not built

- **PSD.** Its pixels are PackBits rows, as some TIFFs' are, but neither ImageMagick's coder (0 of
  13,530 rows of six PSDs given back by libtiff's, a plain greedy one, or one with runs of three) nor
  Photoshop's (53 of 768 rows of a psd-tools test file) is libtiff's. Each writer would need its own
  coder found; not done.
- **TGA with run-length coding.** Six pictures written by Pillow: carried 7% to 19% larger than the
  same pixels uncompressed. Keeping each packet's head as it is (so any writer's choices are kept)
  costs 10,236 to 49,216 bytes under LZMA2: the photographs would gain 3% to 6%, the two screenshots
  lose 17% to 20%. Not built; matching each writer's coder (ImageMagick's literal and run limits
  differ from Pillow's) is what would pay.
- **BMP RLE8 and RLE4.** ImageMagick wrote the pictures uncompressed when asked; not measured.
