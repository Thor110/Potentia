# The x86 filter restarted at each program (11 November 2026)

Found while measuring IDEAS §19.114's third idea, *scattered substitutions* (a file as another with k
bytes changed): what does Sieve make today of a file beside a copy of it changed in a few places?

## Measured first: a file and a copy with k bytes changed

The first 200,000 bytes of a text (Don Quixote, `data/anchors/public-domain/pg996.txt`) and of a
program (this build's `sieve`, Linux x86-64), each beside a copy with k bytes at random places changed
to another value (seed 7). The copy's cost: the pair's `.sieve` less the file's alone (v33, defaults).
The ideal for the changes: log2 C(n, k) + 8k bits.

| Pair | Alone | Pair | The copy's cost | Ideal for the changes |
| --- | ---: | ---: | ---: | ---: |
| text, 10 changed | 50,818 | 51,156 | 338 | 29 |
| text, 100 | | 51,738 | 920 | 255 |
| text, 1,000 | | 54,198 | 3,380 | 2,135 |
| program, 10 changed | 32,425 | 44,928 | 12,503 | 29 |
| program, 100 | | 45,262 | 12,837 | 255 |
| program, 1,000 | | 47,240 | 14,815 | 2,135 |

The program's copy cost 12,503 bytes for 10 changes. Both programs went in the x86 stream, LZMA2
after the x86 filter, which writes each call's and jump's target as the place it goes, counted from
the stream's start: the copy, 200,000 bytes on, has every one of them different, and LZMA2 finds
little to match.

## The filter restarted at each program

Each program filtered from its own start, then one LZMA2 over them all (Python's lzma, preset 9e,
the filter written out in Python and checked to give liblzma's sizes exactly: 45,348 both):

| Programs | Filter over the whole stream | Restarted at each program |
| --- | ---: | ---: |
| 200,000 bytes and a copy, 10 changed | 45,348 | 35,246 |
| 200,000 bytes and a copy, 1,000 changed | 47,928 | 37,990 |
| sieve-install, two builds three days apart (10,246,768 and 10,271,344 bytes) | 4,054,294 | 3,994,999 (-1.46%) |

A program's own matches are the same either way (its targets all move by one amount), so restarting
costs nothing; it gains where programs are alike at the same places.

## Built (v34 draft)

`sieve locate` with the v34 draft, two programs or more: the x86 stream restarted at each (the listing
then v34; SPECIFICATIONS §12.2 v34). The reader and the oracle undo it program by program.

| Pair | v33 | v34 draft | Installed (Sieve, oracle) |
| --- | ---: | ---: | --- |
| program, 10 changed | 44,928 | 34,945 (-22.2%) | the same bytes, both |
| program, 1,000 changed | 47,240 | 37,556 (-20.5%) | the same bytes, both |

The text's copy (338 bytes for 10 changes, against 29) is left as it is: mixing's match model carries
it; a way of its own for scattered substitutions would save about 300 bytes a near copy.
