# Every screen and feature's screenshot, as data (IDEAS 19.202: "each screen gets a screenshot as does
# each feature and those screenshots get tagged with a version number"), made by tools/screenshots.py.
#
# One shot a line, three fields split by " | ":
#   NAME    the picture's name (NAME-vVERSION.png), and the screen or feature it shows
#   DEPENDS the files it is made from, as patterns within Sieve/ split by spaces: when none of them
#           has changed since the shot was last made, it is not made again
#   ARGS    the hallway's arguments for it (--screenshot is added); the words {character} and
#           {world} stand for the files the tool writes beside the shots (seed 99's character; a
#           world with a bookcase and a page)
# Every shot also depends on the language file and the program's version.
