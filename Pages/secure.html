Sieve Secure // Pages That Prove Themselves

Links that name the exact file they point to, checked before it is opened.
AI Disclosure
Sieve is Edward's (Thor110's) work, grown from theory and ideas he has developed over the past few years. Google's Gemini has helped him theorise and conceptualise, and helped write parts of this website. Anthropic's Claude has written much of Sieve's code and documentation with him, including this page and the extension it describes. Transparency fosters trust.
A .sieve file names its contents by their SHA-256, but so could anyone who made one: a file's own hashes only show it was not damaged. Here the link names the hash instead. The page that links to a .sieve states that file's own SHA-256, and the Sieve extension checks it before a byte of the file is opened, refusing anything that does not match.
This is a first test, for Chrome (or Edge) on Windows: the extension hands each checked file to Sieve on your own computer, which unpacks it for the browser.
Set It Up (Four Steps)
  1. Build Sieve from the repository, as on the Build or Buy page (x64 Release).
  2. Double-click Sieve\web\host\install_host.bat, once. It tells Chrome and Edge where your sieve.exe is, for your user only (uninstall_host.bat undoes it).
  3. Open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the Sieve\web\extension folder.
  4. Open the live test site below, or build your own copy and serve it on your computer by double-clicking Sieve\web\test-site\serve_site.bat.
The full guide, for Linux and Mac too, is Sieve/web/README.md.
What You Should See
