# Start Sieve: typing the key no longer opens windows (9 November 2026)

On the GLOBAL "key" row, every letter, digit and - or _ is now typing only: A no longer opens the
alphabets and F no longer opens the filters while you type there. Up/Down, Backspace, Tab, Enter,
Esc and anything with Ctrl or Alt act as before; on every other row A, F and X are shortcuts as before.
Also holds the key hint change (shown only on that row).

Files: Sieve/client/menu.cpp, Sieve/data/lang/en.txt. Replaces sieve-key-hint.zip (holds both).

Checked here: A and F pressed on the key row open nothing; A on the first row still opens the
alphabets.
