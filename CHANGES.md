# Sieve: the October 2026 filters

Unzip over the Potentia repository root (the paths start with `Sieve/`), or apply
`sieve-filters-2026-10.patch` with `git apply` from the repository root. Full write-up:
`Sieve/docs/FILTER-PLUGINS.md` section 19.

## New custom filters (data/filters, no rebuild needed)
- melody-metre-v1, melody-ambitus-v1, melody-gapfill-v1 (audio)
- letter-pairs-v1, letter-triples-v1, word-cost-v1, function-words-v1 (+ .tsv) (pages, lower27)
- sentence-shape-v1 (ascii95), babel-punctuation-v1 (babel29)
  The text ones are generated by tools/build_text_plugins.py from the pinned SCOWL lists.

## New built-in filters (rebuild)
- palette-size-v1, row-runs-v1 (image, video; core/src/filters/picture.cpp)
- canonical-mesh-v1 (models; core/src/modelsieve.cpp) and `sieve mesh --warp F --canonical`
- utf8-valid-v1 (binary; Utf8Counter in core/src/filekind.cpp)
- hard/soft label on every built-in filter (FilterSpec::category), shown by `sieve filters`

## New tools
- tools/build_text_plugins.py (rebuilds the text plugins; --check)
- tools/build_anchor_plugins.py (near an anchor page / contains fragments), examples in tests/plugins
